# TADA! 图然想起 · 项目作品集

湖北美术学院联合设计训练营项目的独立案例网站，按问题发现、调研、设计、开发和测试的顺序展示项目过程。

## 在 Windows 上预览

1. 项目使用 Node.js 18 或更新版本，无需安装 npm 依赖。双击 `start.cmd`，或在此目录打开 PowerShell，运行 `node serve.mjs`。
2. 在浏览器打开 [本地作品集](http://127.0.0.1:4173/)。
3. 结束预览时，在启动窗口按 `Ctrl+C`。如 4173 已被占用，可运行 `node serve.mjs 4174`，再访问 [备用本地地址](http://127.0.0.1:4174/)。

也可以直接双击 `index.html` 预览。建议使用本地服务检查素材、视频进度定位和带章节锚点的页面刷新。

## 修改内容和素材

| 文件或目录 | 用途 |
| --- | --- |
| `index.html` | 项目叙事、章节、引文、图表数据与图片说明 |
| `style.css` | 配色、版式、字体和响应式布局 |
| `app.js` | 导航、图片查看和验收记录交互 |
| `assets/research/` | 调研、分析和早期草图 |
| `assets/design/` | 品牌标志、探索稿与可播放的局部演示录像 |
| `assets/product/` | 线上产品与验收留档的界面截图 |
| `assets/fonts/` | 本地字体及开放字体许可证 |
| `assets/testing/` | 电脑验收截图和 20 条检索记录 |
| `docs/` | 资料盘点、素材对应及待补项 |

替换图片时建议沿用章节目录，保留原始比例，并同步更新 `index.html` 中的文件路径、替代文字和说明。视频使用同目录封面图。演示录像为可用片段，具体出处和覆盖范围见素材对应清单。

本地服务只接收本机访问。页面中的产品介绍和产品演示链接指向原项目现有的公开入口，供查看参考。作品集独立运行，本次交付在本地预览。

## 本地验收

在 Windows Edge 检查了 1440、1024、768、390 和 320 px 五种视口，确认页面无横向溢出。检查了章节导航与锚点刷新、手机菜单、问卷标签切换、图片放大与键盘翻阅、20 条搜索记录筛选、全部页面图片解码和两段 MP4 播放。390 和 320 px 为浏览器视口模拟。直接打开 index.html 也通过了页面交互检查。
